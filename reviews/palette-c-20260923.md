# C 版三色配色修正

Frank 希望橘色為主色調；使用者指出橘色背景與橘子插畫撞色，整頁顏色太花。先前將回饋解讀為文案問題是誤解，品牌段落文字已還原。

介面只用三色：橘 `#cf4615`（主色，主標、餐點區、主要按鈕）、米白 `#fefcfa`（底色）、深綠 `#162b15`（文字與故事區）。橘子插畫所在區改用米白底，保留橘色為主色而不讓插畫融進背景。此插畫另存 C 版配色檔，不改 A 版共用圖檔；照片仍保持原始色彩。

本次只修改 `v2/c/`。修改前版本可由 `v2-c-brand-focus-20260923` 標籤還原。

本機 Playwright 檢查 360、390、768、1440px，無水平溢出或失效圖片。主要區塊背景與介面文字／邊線的計算色值只使用上述三個色相及其透明度；餐點區與品牌段落已逐張檢查手機及桌面截圖。
