# C 版品牌段落修正

使用者指出橘色「水果／老屋／惜物」段落模糊了重點。對照 2026-09-22 Frank 通話紀錄，本站主軸是伍貳居所的老屋客家餐廳，橘二代是父品牌，冰研所是水果冰品延伸；「惜物」可以是背景理念，不適合取代餐廳與品牌關係作為此段主標。

段落改為「橘二代 × 伍貳居所／從橘子園，到老屋裡的餐桌」，並明示在地水果冰品、福菜銅鍋、客家鹹湯圓。圓形標示改為「伍貳居所」，讓視線回到本頁餐廳。A 版與舊版不改。

修改前 Git 標籤：`v2-c-before-brand-focus-20260923`。這次只修改 `v2/c/index.html`、`v2/c/style.css`。

本機 Playwright 檢查 360、390、768、1440px：段落文字沒有橫向溢出，視覺畫面已檢查；768px 特別調整圓形標示與橘枝的重疊。
